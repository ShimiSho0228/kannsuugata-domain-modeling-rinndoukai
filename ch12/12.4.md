### Goで構造体のシリアライズ. 

> [!NOTE]
> Azureへの格納はやめてます…　構造体のJSONシリアライズのみ

```` go
package main

import "encoding/json"
import "fmt"

type Person struct {
	PersionId   int
}

func main() {
	person := Person{PersionId:1}

	// JSONに変換
	jsonBytes, err := json.Marshal(person)
	if err != nil {
        panic(err)
    }

	// JSON出力
    jsonString := string(jsonBytes)
    fmt.Println(jsonString)
}
````
